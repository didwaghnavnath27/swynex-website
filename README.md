# SWYNEX Container or Repeatable Deployment

## Project Description

This project demonstrates containerized deployment of a web application using Docker and Nginx.

The application is packaged into a Docker container so that it can be built and run consistently on different systems.

## Technologies Used

- HTML
- CSS
- JavaScript
- Docker
- Nginx
- Git
- GitHub
